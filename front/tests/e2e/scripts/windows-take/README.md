# 구간2a — 파일 고르는 창까지 담아 찍는다 (윈도우즈)

통합 시나리오의 **구간2a(파일 하나로 서버 여러 대를 한 번에 등록)** 만 여기서 찍는다.
나머지 구간은 리눅스에서 `scripts/record-all.sh` 로 찍고, 이 한 편만 바꿔 끼운다.

## 왜 여기만 따로인가

파일 고르는 창이 이 장면의 요점인데 **그 창은 운영체제가 그린다.** 리눅스에서 찍으면 GTK 창이
나오고, 그 창은 계정 홈을 열어 그 장비의 개발 폴더가 화면에 그대로 남는다. 경로를 타이핑해도 뒤
목록은 바뀌지 않고, 브라우저에 다른 `HOME` 을 줘도 GTK 는 계정 정보를 본다.

윈도우즈에서는 **브라우저 프로필에 "마지막에 쓴 폴더"를 미리 적어 두면** 창이 그 폴더에서 열린다.
프로필이 브라우저보다 먼저 있어야 하므로 `launchPersistentContext` 로 띄운다 — 러너가 만들어
버리는 임시 프로필에 나중에 써 넣으면 늦어서 무시된다.

## 파일

| 파일 | 무엇 |
|---|---|
| `촬영.mjs` | 녹화하며 한 편을 찍는다 |
| `점검.mjs` | 같은 흐름을 녹화 없이 돌려 본다 — 카메라만 끈 예행연습 |
| `흐름.mjs` | 화면에서 하는 일. 촬영과 점검이 **같은 이것을** 쓴다 |
| `조작.mjs` | 윈도우즈 커서를 실제로 옮겨 누른다 |
| `파일창.ps1` | 파일 창 안에서 누를 자리를 찾아 좌표로 알려준다 |
| `파일만들기.mjs` | 창에서 고를 엑셀을 만든다 |
| `설정.mjs` | 값을 `e2e.config` 에서 읽어 온다 |

## 준비

```powershell
# 저장소의 front 에서 — 여기 스크립트는 그 의존성을 함께 쓴다
npm ci
npx playwright install chromium

winget install --id Gyan.FFmpeg -e   # 녹화용. 설치 후 PowerShell 을 새로 연다
```

`tests/e2e/e2e.config` 에 값을 채운다(`e2e.config.example` 을 복사). 이 촬영이 보는 것은
`E2E_PUBLIC_HOST` · `E2E_REAL_HOST` · `E2E_IMPORT_DIR` · `TEST_SOURCE_*` · 로그인 계정이다.

**디스플레이 배율은 100%** 여야 한다. 125% 면 좌표가 어긋나고 담기는 범위도 줄어든다 — 아니면
촬영이 시작하면서 그 사실을 알려 준다.

## 찍기

```powershell
node scripts/windows-take/파일만들기.mjs   # 창에서 고를 파일을 만든다
node scripts/windows-take/촬영.mjs
```

hosts 는 촬영이 알아서 맞춘다 — 없으면 넣고, 지난 회차 값이 남아 있으면 고친다. **IP 는 적어
두지 않고 그때 조회한다**(개발 서버는 켤 때마다 공인 IP 가 바뀐다). 고치려면 관리자 권한이
필요하니 PowerShell 을 관리자로 열어 두면 한 번에 끝난다.

**도는 동안 마우스·키보드를 건드리지 않는다.** 실제 커서를 옮겨 누르므로 다른 창이 앞으로 나오면
엉뚱한 곳이 눌린다.

## 확인

- [ ] **파일 창이 화면에 보이고**, 커서가 파일을 눌러 고른다
- [ ] 주소창이 다른 편들과 같은 이름이다(개발 장비 이름이 아니다)
- [ ] 파일명과 건수가 뜨고, 목록에 그룹이 생긴다
- [ ] 연결 탭에 파일에 있던 서버가 모두 보인다
- [ ] 1920×1080
